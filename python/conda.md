## how to use conda and dowload conda from

[Repo](https://repo.anaconda.com/archive/)

## how to use it after installation and create conda environment

```
conda create -n myenv python=3.11.15 -y
```

## To delete conda environment
```
conda remove --name myenv --all -y
conda clean --all -y
```

## Activate to use this
```
conda activate myenv
```

## Deactivate
```
conda  deactivate
```
